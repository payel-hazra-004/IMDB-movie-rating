# IMDb Movie Rating Web Scraping Project

## 📌 Project Overview
This project demonstrates **web scraping using Python** to extract movie information from the **IMDb Top Movies page**.  
The script collects **movie titles, release years, and IMDb ratings**, then stores the data in a CSV file.

The project is implemented using a **Jupyter Notebook** and focuses on real-world data extraction, HTML parsing, and data storage.

---

## 🎯 Objectives
- Scrape movie data from IMDb
- Extract movie title, release year, and rating
- Store scraped data in a CSV file
- Display extracted data in the notebook output

---

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Libraries:**
  - requests
  - BeautifulSoup (bs4)
  - pandas
- **Environment:** Jupyter Notebook

---

## 📂 Data Collected
- **Source Website:** IMDb (Top Movies Page)
- **Fields Extracted:**
  - Movie Title
  - Release Year
  - IMDb Rating
- **Output File:** `imdb_top_250_movies.csv`

---

## 🔄 Project Workflow
```
Request IMDb Page
        ↓
Parse HTML using BeautifulSoup
        ↓
Extract Movie Details
        ↓
Store Data in DataFrame
        ↓
Export to CSV
```
